# svgraph

[![npm version][npm-version-src]][npm-version-href]

An easy way to generate charts as SVG

## Installation

```bash
npm install svgraph
```

## Development

- Install dependencies

```bash
npm install
```

- Build the project

```bash
npm run build
```

- Run the tests

```bash
npm run test
```

- Format & lint the code

```bash
npm run format
npm run lint
```
